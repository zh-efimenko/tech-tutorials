# Экранирование символов в Markdown

## Принцип

**Символ на месте, а на экране его нет — значит, рендерер прочитал его как разметку.**

Это почти всегда происходит парами: `$0.25 / $2.00` в ячейке таблицы рендерер GitHub видит как inline-формулу и съедает оба доллара вместе с текстом между ними. Автор при этом смотрит в исходник и видит, что всё на месте.

Проверять глазами бесполезно — ломается предсказуемый набор конструкций, и его находит скрипт.

## Инструмент

```bash
python3 .claude/skills/fix-md-escaping/check_md.py AI/radar          # отчёт
python3 .claude/skills/fix-md-escaping/check_md.py --fix AI/radar    # починить автоисправимое
```

Принимает файлы и папки, код возврата 1 при находках (годится для хука). Подробности флагов — `--help`.

## Что скрипт чинит сам

| Класс | Симптом на экране |
|---|---|
| `$` | пара `$…$` на строке исчезает вместе с текстом между ними |
| `<` | `<correctness>` в прозе пропадает: санитайзер GitHub вырезает неизвестный тег |

## Что скрипт только показывает

Эти три класса он не трогает: замена зависит от того, что автор имел в виду.

| Класс | Решение принимает человек |
|---|---|
| `~~` | зачёркивание бывает намеренным |
| `[текст]` при наличии `[текст]: url` в файле | забытый адрес или литеральные скобки |
| `N. ` в начале строки | «2026. Год» станет списком, но настоящий список трогать нельзя |

Отдельно сообщает о структурном, что экранированием не лечится: незакрытый блок кода и строки разной ширины в таблице.

Проверка «у блока кода не указан язык» вынесена под флаг `--strict` и по умолчанию выключена. Конвенция репозитория требует язык у блоков **кода**, но в статьях радара в тройных кавычках чаще лежат тексты промптов и ASCII-диаграммы, у которых языка нет по делу. Включённой по умолчанию эта проверка давала 47 сигналов на корпус `AI/` при одной настоящей находке — и обесценивала весь отчёт.

## Железное правило

**Внутри кода не экранируется ничего.**

Скрипт разбирает строку и пропускает содержимое ` ``` `-блоков, inline-кода в бэктиках, адресов `](...)` и автоссылок `<http…>`. Ручная замена через `sed 's/\$/\\$/g'` этого не умеет и портит примеры: в статье 29 в блоке GitHub Actions лежит `${{ runner.os }}`, а рядом в прозе — бэктики с `${{ github.sha }}`. Глобальная замена превращает оба в `\${{ … }}` — рабочий пример становится нерабочим, и заметно это только при копировании в CI.

Если правишь вручную — правь через скрипт или повторяй его разбор. Не `sed` по всему файлу.

## Частые ошибки

**Экранировать там, где нужны бэктики.** `<correctness>` в прозе — это идентификатор, а не текст. `` `<correctness>` `` читается лучше, чем `\<correctness>`, и заодно снимает проблему. Экранирование — запасной вариант, когда моноширинный шрифт неуместен.

**«Чинить» подчёркивания.** `PROMPTFOO_CACHE_PATH` и `migrate_from_v03_to_v04` в адресе ссылки не ломаются: CommonMark не открывает выделение на `_` внутри слова. Скрипт их и не показывает — добавлять такое правило не нужно, оно даст сотни ложных срабатываний.

**Верить своей модели вместо рендерера.** Правило добавляется только после прогона примера через настоящий парсер:

```bash
python3 -c "from markdown_it import MarkdownIt; print(MarkdownIt('commonmark').render(open('x.md').read()))"
```

Три правила первой версии были выдуманы и не подтвердились: одиночная `*` (`SELECT * FROM`, `A*`, `*.md`) рендерится буквально и курсив не открывает; `[0.7, 0.05]` — тоже, ссылкой становится только при наличии `[0.7, 0.05]: url` в файле; `&amp;` — корректная сущность, даёт `&`. Все три удалены. Осталось то, что воспроизводится: `$…$` (математика GitHub), `<tag>` (санитайзер GitHub) и `2026. ` в начале строки (проверено парсером).

**Добавлять правила без прогона по корпусу.** После парсера — прогон по репозиторию целиком и подсчёт доли ложных срабатываний. Правило про `*` давало 769 сигналов на маркерах списков, правило про язык блока кода — 47 при нуле настоящих находок и уехало под `--strict`. Шумный чекер выключают целиком, вместе с полезными правилами.

**Проверять после публикации.** Файл после конвертации из HTML прогоняется до первого коммита: конвертеры массово порождают ровно эти классы.
