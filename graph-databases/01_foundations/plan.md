# Трек 1. Основы графовых БД и Cypher

## Цель

Понять, какую задачу решает графовая модель данных и где она выигрывает у реляционной, разобраться в ландшафте графовых СУБД, поднять Neo4j локально и свободно писать запросы на Cypher 25 — от простого `MATCH` до обходов переменной длины и quantified path patterns. К концу трека в базе лежит полный датасет курса.

## Что нужно до старта

- Docker Desktop
- Понимание SQL и реляционного моделирования — теория объясняется через сравнение с ним

## Уроки

| #  | Тема | Папка | Описание |
|----|------|-------|----------|
| 01 | Зачем нужны графовые базы данных | `01_why_graph_databases/` | Модель property graph, взрыв JOIN на многоуровневых связях, index-free adjacency, области применимости и случаи, когда граф не нужен |
| 02 | Ландшафт графовых решений | `02_graph_landscape/` | LPG против RDF, сравнение Neo4j, Memgraph, ArangoDB, Neptune, JanusGraph и Apache AGE, стандарт ISO GQL, редакции Neo4j |
| 03 | Запуск Neo4j и инструменты | `03_setup_and_tools/` | compose.yml, Neo4j Browser, cypher-shell, ключевые настройки памяти, плагины APOC и GDS |
| 04 | Модель данных | `04_data_model/` | Узлы, метки, связи, свойства, типы данных, направленность, elementId, первые данные руками |
| 05 | Cypher: чтение данных | `05_cypher_read/` | MATCH и синтаксис паттернов, WHERE, RETURN, DISTINCT, ORDER BY, SKIP, LIMIT, OPTIONAL MATCH |
| 06 | Cypher: запись данных | `06_cypher_write/` | CREATE, семантика MERGE, SET, REMOVE, DELETE и DETACH DELETE, идемпотентность, параметры |
| 07 | Cypher: обходы и агрегации | `07_cypher_traversal/` | Пути переменной длины, WITH как конвейер, агрегации, collect и UNWIND, функции списков и map, shortestPath |
| 08 | Cypher 25: что нового | `08_cypher25_features/` | Quantified path patterns, соответствие GQL, отличия от Cypher 5, выбор версии языка |
| 09 | Загрузка данных | `09_data_loading/` | LOAD CSV, CALL {} IN TRANSACTIONS, neo4j-admin import, загрузка через APOC, полный датасет курса |

## Порядок

Строго последовательно. Уроки 05-08 наращивают язык шаг за шагом, каждый следующий использует конструкции предыдущего. После урока 09 в базе лежат данные, на которых работают все остальные треки — этот урок пропускать нельзя.
