# Трек 4. Графовые алгоритмы и GDS

## Цель

Освоить библиотеку Graph Data Science: проецировать граф в память, запускать алгоритмы центральности, выделения сообществ, similarity и поиска путей, интерпретировать результаты и записывать их обратно в граф. Понимать стоимость алгоритмов по памяти и времени.

## Что нужно до старта

- Треки 1 и 2 — датасет загружен, индексы созданы
- Плагин `graph-data-science` подключён (уже есть в `compose.yml`)

Трек 3 не требуется: всё выполняется через Cypher. Если нужны только алгоритмы без Java-интеграции, маршрут 1 → 2 → 4 → 5 полностью рабочий.

## Уроки

| #  | Тема | Папка | Описание |
|----|------|-------|----------|
| 25 | Введение в GDS | `25_gds_intro/` | Что даёт библиотека, проекции графа, каталог графов, режимы stream, write и mutate, оценка памяти, ограничения Community |
| 26 | Центральности | `26_centrality/` | Degree, PageRank, betweenness, closeness, eigenvector, интерпретация результатов на графе магазина |
| 27 | Выделение сообществ | `27_community_detection/` | Louvain, Leiden, WCC, SCC, label propagation, модулярность, подбор параметров |
| 28 | Similarity и эмбеддинги | `28_similarity_embeddings/` | Node Similarity, KNN, FastRP и GraphSAGE, node embeddings и их практическое применение |
| 29 | Поиск путей | `29_pathfinding/` | Dijkstra, A*, Yen's K-shortest paths, минимальное остовное дерево, навигация по каталогу |

## Порядок

Урок 25 обязателен первым — без понимания проекций остальные алгоритмы не запустятся. Уроки 26-29 независимы друг от друга, порядок выбирается по задаче: центральности для влияния, сообщества для сегментации и антифрода, similarity для рекомендаций, пути для навигации и логистики. Результаты уроков 27 и 28 используются в треке 5.
